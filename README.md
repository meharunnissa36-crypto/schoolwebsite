# Basharat Higher Secondary School (BHSS) - Official Web Portal

Welcome to the official web portal repository for **Basharat Higher Secondary School (BHSS)**. This repository houses the complete, responsive multi-page web platform featuring heritage aesthetics, academic curriculum pathways, boarding house wings, news, and admissions portals.

## 🌟 Key Features
- **15 Standardized Pages**: Comprehensive coverage of academics, boarding, co-curriculars, fee structure, calendars, principal's letters, bulletins, and admissions.
- **Responsive Navigation**: Full desktop navigation bar with dropdown menus and a mobile drawer covering every page.
- **Sticky WhatsApp Admissions Desk**: Real-time WhatsApp query widget with pulse effect.
- **Ultra-Fast Performance**: Zero external heavy runtimes, optimized SVG graphics, pure HTML5/CSS3/Vanilla JS.
